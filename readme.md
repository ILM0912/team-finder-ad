# TeamFinder

TeamFinder — веб-приложение для поиска команд и совместной работы над проектами.

Пользователи могут:
- создавать проекты;
- искать интересные проекты;
- присоединяться к командам;
- добавлять проекты в избранное;
- редактировать профиль;
- управлять своими проектами.

---

## Технологии

Проект разработан с использованием следующих технологий:

- Python 3.10
- Django
- PostgreSQL
- Docker / Docker Compose
- Gunicorn
- HTML / CSS / JavaScript

---

## Функциональность

### Для пользователей:
- регистрация и авторизация;
- редактирование профиля;
- просмотр списка проектов;
- фильтрация пользователей;
- участие в проектах;
- добавление проектов в избранное.

### Для авторов проектов:
- создание проекта;
- редактирование проекта;
- завершение проекта.

### Для администратора:
- управление пользователями;
- управление проектами;
- просмотр данных через Django Admin.

## Установка и запуск проекта

### 1. Клонировать репозиторий

```bash
git clone <repo_url>
cd team-finder
```

### 2. Создать .env

```bash
cp .env_example .env
```

Заполните переменные:

```env
DJANGO_SECRET_KEY=change_for_safety
DJANGO_DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

POSTGRES_DB=team_finder
POSTGRES_USER=team_finder
POSTGRES_PASSWORD=team_finder
POSTGRES_HOST=db
POSTGRES_PORT=5436
```

### 3. Запуск через Docker
```bash
docker compose up --build
```

Остановить:

```bash
docker compose down
```

Для заполнения тестовыми данными в Dockerfile есть строчка
```Dockerfile
CMD
  ...
  python manage.py loaddata db.json && \
  ...
```

Ее можно убрать если тестовые данные не нужны.
